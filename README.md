# Rewilding_Hotspots_Spatial_Prioritisation_Framework_Britain_Case_Study
Code and data supporting a spatial framework for identifying candidate trophic rewilding hotspots across Britain. This repository brings together the analyses, datasets, and outputs used to assess opportunities for restoring multiple mammal species under current land-cover conditions.

**Statement of Authorship:** MEA, DAO and CFC conceived and designed the study and analysis. MEA collected and cleaned the data. MEA, CFC and DOB analysed the data. MEA wrote the first draft of the manuscript whilst DAO, JM and CFC contributed to writing and editing the manuscript. All authors approved of the manuscript before publication.

**Data Accessibility Statement:** All source datasets used in this study are publicly available. Land-cover data were obtained from the UK Centre for Ecology & Hydrology’s (UKCEH) Land Cover Map 2023 for Britain (Morton et al., 2024), available at https://doi.org/10.5285/50b344eb-8343-423b-8b2f-0e9800e34bbd. Minimum viable population estimates for Eurasian beaver, European bison, northern lynx, wild boar, Eurasian wolf, and wolverine were obtained from the [supplementary dataset accompanying Traill et al. (2007)](https://ars.els-cdn.com/content/image/1-s2.0-S0006320707002534-mmc1.xls). Population-density estimates were obtained from the [supplementary dataset accompanying Santini et al. (2022)](https://onlinelibrary.wiley.com/action/downloadSupplement?doi=10.1111%2Fgeb.13476&file=geb13476-sup-0002-TableS1.xls), and home-range data were obtained from the [Dryad dataset associated with Broekman et al. (2024)](https://datadryad.org/downloads/file_stream/2572025).
Road data were obtained from the [Ordnance Survey Open Roads dataset (Ordnance Survey, 2024)](https://osdatahub.os.uk/data/downloads/open/OpenRoads). Railway data (Pope, 2017a) and river and canal data (Pope, 2017) were obtained from Edinburgh DataShare; direct downloads are available for the [railway dataset](https://datashare.ed.ac.uk/bitstreams/59b5a5ac-26a5-4de6-94f8-015dea62f391/download) and the [river and canal dataset](https://datashare.ed.ac.uk/bitstreams/2b6a7f70-64b8-4adc-9651-9aea9b2c903f/download). Dataset selection and processing procedures are described in the Methods and Supplementary Information.

**Codes:**
_1) Land Coverage Reclassification Script_ - Reclassification of the UKCEH 21 land coverage types into 13 simplified types.
This script processes a national land cover raster for Britain by masking it to a dissolved England–Scotland–Wales boundary, aggregating the raster to a lower spatial resolution using a custom modal function, and reclassifying 21 original land cover classes into 13 broader categories. The workflow outputs a reclassified raster and a static JPEG map.
_2) Hs Code_ - Formation of habitat suitability (HF) maps
This script generates binary habitat suitability maps for focal species in Britain by reclassifying a national land cover raster using species-specific suitability rules. For each species, land cover classes are converted to suitable (1) or unsuitable (0) habitat based on a reference table, masked to a dissolved England–Scotland–Wales boundary, and exported as both a GeoTIFF and a static JPEG map. The script additionally compiles all species-specific suitability rasters into a single multi-panel figure for comparative visualisation.
_3) Buffering Hs Maps Code_ - Assigning species dispersal distance as a buffer (DCP)
This script expands species-specific suitable habitat maps by applying dispersal-distance buffers to account for landscape connectivity and potential movement. For each species, binary habitat suitability rasters are buffered by species-specific dispersal distances, processed separately within England, Scotland, and Wales, and mosaicked into a single Great Britain–wide raster. Resulting habitat patches are then clustered and filtered to retain only those exceeding species-specific minimum area requirements. The script exports buffered and filtered habitat rasters as GeoTIFFs, generates individual JPEG maps for each species, and produces a combined multi-panel figure for comparative visualisation.
_4) Processing and Combining Dispersal Barriers Script_ - Dispersal barriers: build + combine (GB)
This script (1) identifies and exports four dispersal barrier layers (major roads, canals, railways, wide rivers) from source datasets, produces a JPEG map for each barrier type, and (2) combines all barrier layers (plus coastline) into a single GeoJSON and a combined JPEG map.
_5) Splitting Centroid Patches with Barriers_ - Splitting buffered suitable habitat patches by barriers (BCP)
This script refines species-specific buffered habitat maps by explicitly accounting for dispersal barriers and minimum patch size constraints. For each species, buffered suitable habitat rasters are converted to polygons, convex hulls are generated for contiguous patches, and these patches are split using multiple barrier types (roads, rivers, canals, railways, and coastline). Resulting habitat fragments are rasterised, reclassified, and filtered to retain only patches exceeding species-specific minimum area requirements. The workflow outputs final filtered habitat rasters, spatial patch layers, patch-level and species-level summary tables, and publication-ready maps with dispersal barriers overlaid.
_6) Heat Map and Visulisation Script_ - Species habitat maps, patch maps, and overlap heatmap
This script visualises final species habitat outputs by (1) plotting binary suitable habitat maps for all species in a multi-panel figure, (2) plotting patch-ID maps (one panel per species) with dispersal barriers overlaid, and (3) computing and mapping the number of species overlapping per pixel across Great Britain as a heatmap. Outputs are saved as publication-ready JPEGs.
_7) Phylogenetic Maps and Faith's PD Code_- Phylogenetic relationships, pairwise distances and Faith's Phylogenetic Diversity for ten focal species
R code calculating pairwise phylogenetic distances among ten focal mammals and Faith’s phylogenetic diversity for all 1,013 possible multi-species assemblages across 100 trees. Exports summary tables, comparisons among assemblages of equal species richness, a representative phylogenetic tree, and a distance heatmap.
_8) Rewilding Hotspot Population Capacity Analysis_ - Identify and characterise rewilding hotspots using Faith's Phylogenetic Diversity and potential population capacity
This script partitions Great Britain into barrier-defined polygons and identifies the focal species supported by each, assigning viable patches where at least 95% of their area falls within a polygon. It summarises patch numbers, viable habitat area, species-specific MARs and MVPs, MVP equivalents, and potential population sizes. Multi-species assemblages are matched to Faith’s phylogenetic diversity values calculated across 100 dated VertLife mammal phylogenies. Outputs include species-support and hotspot summary tables, patch-level and population-capacity tables, an unranked phylogenetic diversity map, and hotspot polygons in GeoJSON format, linked by the permanent identifier `barrier_poly_id`.
_9) Rewilding Hotspot Viability Headroom Analysis_ - Rewilding hotspot viability headroom analysis
This script calculates species-specific viability headroom from hotspot × species population-capacity data, expressing both total viable habitat area and largest viable patch area relative to each species’ Minimum Area Requirement (MAR). It applies a log₂(1 + ratio) transformation to reduce the influence of exceptionally large habitat-to-MAR ratios, summarises the transformed values for each hotspot, and exports species-level and hotspot-level headroom tables.
_10) Rewilding Hotspot Metric Maps_ - Generate rewilding hotspot metric maps
This script produces a three-panel map of candidate rewilding hotspots showing species richness, Faith’s phylogenetic diversity, and mean viability headroom score. Species richness is displayed with a discrete legend, while phylogenetic diversity and mean headroom use continuous colour scales.
_11) Species Patch Summary and Dispersal MAR Analysis_ - Summary table combined stats (split with barriers)
This script summarises species-level habitat patch statistics from Excel outputs generated after suitable habitat has been split by dispersal barriers. For each species file, the script calculates the number of remaining habitat patches, total suitable habitat area, mean, median and standard deviation of patch area, largest patch size, the percentage of total habitat contained within the largest patch, and a domination index describing how evenly habitat area is distributed among patches. Empty or invalid files are skipped, and all valid species summaries are combined, sorted alphabetically, and exported as a single overview Excel table.
